# ai-incident-investigator
A Python-based incident investigation tool that analyses system logs, classifies incidents using rule-based logic, and integrates Google's Gemini LLM to generate root-cause hypotheses and troubleshooting recommendations.

## Problem

Investigating system logs manually can be repetitive and time-consuming. This project explores how Python automation and large language models (LLMs) can support a more structured incident investigation workflow.

## Features

- **Log parsing:** Reads and processes system log entries.
- **Error classification:** Identifies errors and groups them by camera.
- **Severity assessment:** Assigns incident severity using configurable Python rules.
- **Root-cause investigation:** Generates preliminary hypotheses from observed error patterns.
- **Structured reporting:** Stores incident details and evidence in JSON format.
- **LLM integration:** Uses Google's Gemini API to summarise incidents and suggest investigation steps.
- **Unit testing:** Tests core severity rules, investigation logic, and prompt construction.

## How It Works

1. Read sample logs from `sample_logs.txt`.
2. Identify and group error entries by camera.
3. Determine incident severity using rule-based logic.
4. Generate a structured incident report.
5. Send incident evidence to Gemini for additional analysis.
6. Return possible causes, recommended checks, and information needed to confirm the root cause.

## Example Scenario

The sample dataset simulates a camera-system incident involving:

- Repeated detection-service timeouts.
- A failed detection-event publishing operation.
- A warning about frame-processing latency.

The Python rules classify the incident as **HIGH** severity. Gemini then proposes possible explanations and recommends additional checks.

These explanations are hypotheses, not confirmed root causes. Further logs, service metrics, and network evidence would be needed to establish the actual cause.

## Setup

### 1. Install Python

Install Python from [python.org](https://www.python.org/downloads/).

### 2. Install dependencies

```bash
python -m pip install google-genai
```

### 3. Configure the Gemini API key

Set the `GEMINI_API_KEY` environment variable using a key obtained through [Google AI Studio](https://aistudio.google.com/).

Never commit API keys or other secrets to the repository.

### 4. Run the incident analysis

```bash
python main.py
```

This generates `incident_report.json`.

### 5. Run the Gemini investigation

```bash
python ai_analyze.py
```

This sends the generated incident report to Gemini for further analysis. API availability and usage limits may apply.

### 6. Run the tests

```bash
python -m unittest test_incident -v
```

## Current Limitations

- Uses synthetic logs rather than live production telemetry.
- Severity classification is based on predefined rules.
- Root-cause suggestions are generated by an LLM and require human verification.
- No live CCTV feed, monitoring platform, or production system is connected.
